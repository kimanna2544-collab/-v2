# TOEIC MASTER 2.0

기존 PWA의 업그레이드 버전입니다. 유형별 학습, 실전 풀이, 북마크, 진도 저장, 확장 해설, 오프라인 캐시를 제공합니다.

## 모바일 GitHub Pages 업데이트
1. ZIP 압축을 풉니다.
2. 기존 GitHub 저장소의 최상위(root)에 **ZIP 자체가 아닌 내부 파일 전체**를 업로드하고 같은 이름의 파일은 덮어씁니다.
3. Settings > Pages > Deploy from a branch > main > /(root)로 설정합니다.
4. 배포 완료 후 사이트를 새로고침합니다. 이전 화면이 보이면 Chrome에서 사이트 데이터를 갱신하거나 앱을 재실행합니다.

주의: 현재 문제는 자체 제작 Part 5 연습문제 30개이며, 해설의 문법 팁은 유형별 공통 설명입니다. 실제 기출문제 또는 공식 TOEIC 문제은행이 아닙니다. 기기 브라우저 저장소를 삭제하면 학습 기록도 사라질 수 있습니다.
